随堂练习三-摩托车里程碑问题

📝题目展示

李刚骑摩托车在公路上高速匀速行驶：

• 早晨7:00时看到里程碑上的数是一个两位数，它的数字之和是9

• 8:00时看里程碑上的两位数与7:00时看到的个位数和十位数颠倒了

• 9:00时看到里程碑上的数是7:00时看到的数的8倍

请问：李刚在7:00时看到的数字是多少?

🔍问题分析

首先，我们需要理解题目给出的信息：

1. 设7:00时看到的两位数为\(10x + y\)，其中x是十位数字，y是个位数字

2. 根据题意，数字之和：\(x + y = 9\)

3. 8:00时看到的数字是\(10y + x\)（数字颠倒）

4. 9:00时看到的数字是\(8(10x + y)\)

5. 李刚匀速行驶，所以8:00到9:00行驶的路程等于7:00到8:00行驶的路程

由于李刚匀速行驶，相邻时间段行驶的路程相等：

8:00里程碑数 - 7:00里程碑数 = 9:00里程碑数 - 8:00里程碑数

即：

\[(10y + x) - (10x + y) = 8(10x + y) - (10y + x)\]

📐建立方程

根据题意，我们可以建立以下方程：

\[x + y = 9\]

\[(10y + x) - (10x + y) = 8(10x + y) - (10y + x)\]

首先简化第一个方程：

第一步：简化数字颠倒的差

\((10y + x) - (10x + y) = 10y + x - 10x - y = 9y - 9x = 9(y - x)\)

第二步：简化第二个差

\(8(10x + y) - (10y + x) = 80x + 8y - 10y - x = 79x - 2y\)

第三步：建立等式

\(9(y - x) = 79x - 2y\)

🧮解方程

现在我们有两个方程：

\[ \begin{cases} x + y = 9\\ 9(y - x) = 79x - 2y\ \end{cases} \]

第一步：展开第二个方程

\(9(y - x) = 79x - 2y\)

\(9y - 9x = 79x - 2y\)

\(9y + 2y = 79x + 9x\)

\(11y = 88x\)

\(y = 8x\)

第二步：代入第一个方程

\(x + y = 9\)

\(x + 8x = 9\)

\(9x = 9\)

\(x = 1\)

第三步：求y的值

\(y = 8x = 8 \times 1 = 8\)

第四步：确定7:00看到的数字

7:00看到的数字是 \(10x + y = 10 \times 1 + 8 = 18\)

✅验证答案

我们得到的答案是：李刚在7:00时看到的数字是18

让我们验证一下：

• 7:00：数字18，数字之和 \(1 + 8 = 9\) ✓

• 8:00：数字颠倒为81 ✓

• 9:00：数字是7:00数字的8倍，\(18 \times 8 = 144\) ✓

• 检查匀速行驶：

7:00到8:00行驶距离：\(81 - 18 = 63\)公里

8:00到9:00行驶距离：\(144 - 81 = 63\)公里 ✓

最终答案

李刚在7:00时看到的数字是 18

📚总结

解题关键点

1. 正确设未知数：用\(10x+y\)表示两位数

2. 理解数字颠倒的含义：\(10y+x\)

3. 利用匀速行驶建立方程：相邻时间段行驶距离相等

4. 解方程组，注意x和y必须是0-9的整数

5. 验证答案是否符合所有条件

类似问题的通用解法

对于这类"里程碑问题"，可以总结出通用解法：

设初始数字为\(10x+y\)，数字和为\(s\)，倍数为\(k\)

则：

\[x + y = s\]

\[(10y + x) - (10x + y) = k(10x + y) - (10y + x)\]

化简后解方程组即可。
